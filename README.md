A modern, responsive, enterprise-style portfolio website for a Senior Android Developer and Full Stack Engineer.

## Live Website

https://dev-moe-kyawaung.github.io/supreme-portfolio-v6/

## Overview

Supreme Portfolio V6 is a multi-page static portfolio built with modern frontend technologies and a futuristic enterprise visual style.

The website presents professional experience, Android development services, technical skills, projects, community involvement, open-source activity, mentoring, and contact information.

## Portfolio Parts

| Page | Sections | File |
|---|---:|---|
| Part 1 | 11-20 | `index.html` |
| Part 2 | 21-40 | `part2.html` |
| Part 3 | 41-50 | `part3.html` |

## Features

- Responsive enterprise portfolio layout.
- Dark-themed glassmorphism interface.
- Bootstrap 5 responsive grid system.
- AOS scroll animations.
- Smooth in-page navigation.
- Multi-page navigation between portfolio parts.
- Android developer profile sections.
- Services and pricing sections.
- Technical skills and development toolkit.
- GitHub and social media links.
- Blog, testimonials, awards, certificates, and projects.
- Contact inquiry form.
- GitHub Pages deployment support.
- Reusable shared CSS and JavaScript files.
- Mobile-friendly navigation.

## Technology Stack

- HTML5.
- CSS3.
- JavaScript.
- Bootstrap 5.3.3.
- Font Awesome 6.5.2.
- AOS 2.3.4.
- Google Fonts.
- GitHub Pages.

## Local Development
This is a static website, so no Node.js installation is required for the basic version.
##  Option 1: VS Code Live Server
Open the project in VS Code.
  Install the Live Server extension.
Right-click index.html.
   Select Open with Live Server.
##   Option 2: Python HTTP Server
```
python -m http.server 5500
