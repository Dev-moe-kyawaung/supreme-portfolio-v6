# Security Policy

## Supported Versions

Only the latest version deployed to the default branch is actively maintained.

| Version | Supported |
|---|---|
| Latest | Yes |
| Older versions | No |

## Reporting a Vulnerability

Please do not report security vulnerabilities in public issues.

Send a private report through:

- Email: moekyawaung@programmer.net
- GitHub private security advisory, if enabled

Please include:

- A clear description of the issue.
- Steps to reproduce.
- The affected file or URL.
- Potential impact.
- Suggested mitigation, if available.

## Response Process

I will review valid security reports and provide a response as soon as reasonably possible.

Please avoid publicly disclosing the issue until a fix or mitigation is available.
